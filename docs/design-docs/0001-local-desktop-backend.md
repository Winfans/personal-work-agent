# 0001 — 本地桌面端与后端边界

- 状态：已采纳
- 日期：2026-10-16（记录现有设计）

## 背景

桌面界面需要聊天、路由、检索和持久化能力，而服务商及数据库凭证不能进入面向浏览器的代码。

## 决策

使用 Electron/React 呈现界面，由单独运行在本机的 FastAPI 服务承担应用逻辑、凭证管理和外部集成。

## 影响

- UI 与后端可以分别测试。
- 完整的笔记体验需要两个运行环境和 MySQL。
- 本地监听地址及 CORS 是安全相关契约。
- 远程部署或将后端嵌入 Electron 需要重新设计。

## 备选方案

渲染进程直接访问外部服务会暴露凭证。将所有功能移入 Electron 主进程虽可减少进程数量，却会混合桌面生命周期与应用服务；现有代码未采用此方案。

## 代理实施提示

不要把服务商或数据库凭证移入渲染进程。进程拓扑或信任边界变化需新增取代此记录的决策，并协调验证 UI 与后端。
