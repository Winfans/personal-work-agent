# 0003 — MySQL 笔记持久化

- 状态：提议中；当前工作区已有实现
- 日期：2026-10-16

## 背景

笔记需要持久保存，并沿用桌面端和后端之间的信任边界。

## 决策

FastAPI 负责 CRUD 验证与持久化。服务层通过注入的异步 SQLAlchemy 会话访问 MySQL；渲染进程仅通过 HTTP 访问笔记。

## 影响

- 持久化集中管理，隔离测试可以替换 service。
- 完整运行验证需要 MySQL。
- 当前生命周期初始化使后端启动依赖数据库可用。
- 迁移、备份、恢复及降级运行方式尚未确定。

## 备选方案

渲染进程本地存储较简单，但绕过后端。SQLite 可简化本地安装，不过与当前工作区的实现不符。

## 代理实施提示

取得集成验证证据前，不应将此决策标为已采纳。没有迁移与恢复设计时，不执行破坏性 schema 或数据卷操作。
