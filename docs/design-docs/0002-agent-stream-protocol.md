# 0002 — Agent 的 NDJSON 流协议

- 状态：已采纳
- 日期：2026-10-16（记录现有设计）

## 背景

UI 需要增量文本，同时让用户看见路由和检索进度。

## 决策

通过 HTTP 返回按行分隔的 JSON，事件顺序为 `start`、`route`、可选 `retrieval`、若干 `delta`、`done`；流开始后的失败使用 `error`。

## 影响

- UI 可以及早显示输出和状态。
- 事件顺序及字段是前后端共同遵守的兼容性契约。
- 解析器必须缓存不完整的行，支持取消，并处理响应头发送后的错误。

## 备选方案

单个 JSON 响应无法提供渐进反馈。SSE 或 WebSocket 也可行，但需要明确的协议迁移。

## 代理实施提示

协议变更须同步修改后端测试、渲染进程解析器及类型、产品规格，并考虑 `/chat/text` 的兼容性。
