# 笔记工作台

## 用户目标

用户可以在桌面工作台创建、列出、选择、编辑、保存和删除持久笔记。

## 行为

- 列表从后端加载；有结果时选中第一条。
- 新笔记具有默认标题和空正文。
- 保存时标题不能为空。
- 删除前需要确认；删除后选择下一条可用笔记。
- 加载、保存、空列表和失败状态应可见。
- 笔记不存在时后端返回 HTTP 404。
- 成功响应使用 `code: 0`、`message: "OK"`，笔记或列表放在 `data`；删除成功时 `data` 为 `null`，HTTP 状态为 200。
- 错误响应使用非零 `code`、错误 `message` 和 `data: null`，并保留相应 HTTP 错误状态。

## 数据

笔记包含整数 ID、标题、正文、创建时间及更新时间。当前工作区使用 MySQL 作为预期的持久化存储。
