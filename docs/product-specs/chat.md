# 聊天与知识检索

## 用户目标

用户发送对话后，及时看到处理状态和逐步生成的回答。涉及私有或项目知识的问题可以使用已配置的知识库。

## 行为

- 回答流式生成期间，发送操作不可用。
- 新对话清空本地消息状态，并取消正在进行的请求。
- 路由结果显示普通聊天或知识库聊天。
- RAG 在生成前报告检索结果数量。
- `delta` 事件的文本逐步呈现。
- 连接或服务商失败时显示错误，UI 不应崩溃。

## 契约

`POST /agent/run` 接受消息历史或兼容的单条消息。事件流遵循[设计记录 0002](../design-docs/0002-agent-stream-protocol.md)。`/chat/text` 仍与同一 Agent 行为兼容。

流开始前若请求校验或服务配置失败，接口返回统一 JSON 错误结构；流开始后的失败继续用 `error` 事件报告。
