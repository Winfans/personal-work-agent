# 产品原则

## 产品承诺

Personal Work Agent 应是可靠的本地工作台：提供快速的对话协助、清晰的私有知识使用方式和持久的笔记，同时不让用户承担底层基础设施的复杂性。

## 优先级

1. 信任和数据安全优先于自主化能力。
2. 清晰的进度及失败状态优先于装饰性打磨。
3. 本地交互要及时，流式反馈要明确。
4. 功能应组成连贯的工作台体验。
5. 交付可端到端检查和验证的功能。

## 产品边界

- 当前仓库是个人本地应用，并非多租户服务。
- 私有知识检索应区分有来源的信息与模型自行生成的内容。
- 笔记是用户数据；持久性、备份和恢复优先于功能数量。
- 对话能力不代表获得执行外部操作的权限。

## 需要由使用者决定的问题

- 支持的平台及分发方式。
- 聊天和会话历史是否持久化。
- 服务商或数据库不可用时的降级行为。
- 隐私、保留期限、备份和恢复策略。
- 下一步增加哪些工作台能力。
