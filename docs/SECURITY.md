# 安全与隐私

## 信任边界

- 渲染进程不应获取服务商或数据库凭证。
- FastAPI 是凭证管理和外部集成的边界。
- 服务商、RAG 和 MySQL 的响应均视为不可信输入，需要验证。
- 本地监听地址和 CORS 配置决定哪些本地调用方可以访问后端。

## 规则

- 不提交真实密钥、私有索引标识或生产服务地址。
- 示例配置使用明确的占位值。
- 不记录授权请求头或凭证。
- 未确定脱敏和保留策略前，避免记录完整用户消息、私有检索文档或服务商响应。
- 验证数据库标识符和外部响应结构。
- 破坏性数据库操作需要明确范围、备份及恢复步骤。
- 依赖升级须单独验证，不应混入功能改动。

## 已知缺口

- 尚无针对本地恶意网页或进程访问后端的威胁模型。
- 桌面端尚无安全凭证存储方案。
- 仓库内没有自动化密钥、依赖及安全扫描。
- 外部响应验证与日志脱敏尚不完整。
- 尚无数据保留或删除策略。

安全敏感的变更需要设计记录和针对失败情形的测试。
