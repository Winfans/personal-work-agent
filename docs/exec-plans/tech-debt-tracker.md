# 技术债追踪

| 编号 | 问题 | 影响 | 证据位置 | 建议下一步 |
| --- | --- | --- | --- | --- |
| TD-001 | 缺少仓库级统一检查命令 | 代理需要记住多个组件命令 | 根目录及组件配置 | 增加跨平台的简短验证入口 |
| TD-002 | 架构边界仅由文字约束 | 依赖漂移发现较晚 | `ARCHITECTURE.md` | 明确并测试允许的导入关系 |
| TD-003 | 缺少 MySQL 迁移流程 | Schema 演进与回滚有风险 | 数据库初始化代码 | Schema 扩展前选定迁移方案 |
| TD-004 | 渲染进程硬编码后端地址 | 打包及配置较脆弱 | 渲染进程 API 模块 | 设计运行时端点配置 |
| TD-005 | 缺少 UI 自动交互测试 | 构建通过时用户流程仍可能失效 | `QUALITY_SCORE.md` | 覆盖最关键的用户流程 |
| TD-006 | 日志可能包含服务商/RAG 响应内容 | 存在隐私和凭证暴露风险 | 后端 service 日志 | 制定并执行脱敏和保留策略 |
| TD-007 | 缺少结构化可观测能力 | 代理无法查询流程、延迟或故障率 | `RELIABILITY.md` | 增加关联 ID、结构化日志，再考虑指标和链路 |
| TD-008 | 文档缺少自动漂移检查 | 项目知识可能悄然过期 | `docs/` | 检查链接、目录登记及时效 |
